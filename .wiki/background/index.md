# Background

Active contributors: rizaldy, docmeth02, Piekay, Francesco, faultables, SindreKjelsrud, Ed Poe, Simon Risse.

The background lens explains why flo is built the way it is. These pages are not step-by-step guides; they are context for contributors who need to understand trade-offs, known rough spots, and version-to-version changes.

- [Design decisions](design-decisions.md): Why the project uses singletons, Core Data, two API surfaces, a file-backed credential store on Catalyst, and the current folder layout for downloads and caches.
- [Pitfalls](pitfalls.md): Known FIXME/TODO comments and rough areas that can trip up changes.
- [Migration context](migration-context.md): Version changes that affect upgrades, container names, and compatibility.
