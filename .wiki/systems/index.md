# Systems

Active contributors: rizaldy, docmeth02, Piekay, Francesco, faultables, SindreKjelsrud, Ed Poe, Simon Risse.

The systems lens explains how flo keeps the music playing. Each page focuses on a single subsystem: the files that implement it, the abstractions that matter, and the typical flow through the code.

- [Networking](networking.md): Navidrome and Subsonic endpoints, authentication, retries, and debug logging.
- [Persistence](persistence.md): Core Data, UserDefaults, Keychain, the Catalyst file-backed credential store, local file system, and caches.
- [Player engine](player-engine.md): The AVPlayer wrapper, remote control, now-playing metadata, and queue management.
