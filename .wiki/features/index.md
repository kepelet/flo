# Features

This section describes the major features of flo. Each page explains the purpose, key abstractions, and how the feature is wired into the rest of the app.

- [Audio playback](audio-playback.md) — The media player, queue, lyrics, remote controls, and AirPlay.
- [Library browsing](library-browsing.md) — Home, library, artists, albums, songs, playlists, radios, and search.
- [Offline downloads](offline-downloads.md) — Downloading albums, playlists, and songs for offline playback.
- [Watch companion](watch-companion.md) — The watchOS app and playback control from the watch.
- [CarPlay](carplay.md) — The CarPlay interface for in-car playback.
- [Scrobbling and stats](scrobbling-stats.md) — Listening history, stats, and scrobbling to external services.
- [IAP and authentication](iap-authentication.md) — Standard login and IAP/OAuth2-Proxy authentication.
